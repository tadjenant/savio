Подключение Google Таблицы
▶
Позволяет загружать чеки прямо из Google Таблицы. Настраивается один раз. Нужен аккаунт Google.
Пошаговая настройка Apps Script:
1
Откройте вашу Google Таблицу с чеками → нажмите Расширения → Apps Script
2
Удалите весь код в редакторе и вставьте этот:
function doGet(e){ var url=e.parameter.url; var ss=url ?SpreadsheetApp.openById( url.match(/\/d\/([a-zA-Z0-9_-]+)/)[1]) :SpreadsheetApp.getActiveSpreadsheet(); var d=ss.getActiveSheet() .getDataRange().getValues(); return ContentService .createTextOutput(JSON.stringify({ok:true,data:d, sheet:ss.getActiveSheet().getName()})) .setMimeType(ContentService.MimeType.JSON); }
3
Нажмите 💾 Сохранить → затем Развернуть → Новое развертывание
Тип: Веб-приложение · Доступ: Все
→ Нажмите Развернуть → разрешите доступ → скопируйте URL
4
Вставьте скопированный URL в раздел Чеки → Google Таблица и нажмите Сохранить. Готово — настройка сохраняется навсегда.
5
Структура Google Таблицы:
Первая строка — заголовки столбцов. Рекомендуемые названия:
Наименование  |  Количество  |  Цена  |  Сумма
Со второй строки — позиции товаров.

Итоговая строка (обязательно):
Последняя строка таблицы должна содержать итоговую сумму. В первом столбце напишите слово Итого (или Total), а в столбце с суммой укажите итоговое значение — именно эту цифру приложение считывает как общую сумму чека.

Пример последней строки:
Итого  |   |   |  15 430
Если строки «Итого» нет — приложение посчитает сумму всех позиций автоматически.
